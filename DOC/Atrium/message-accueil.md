# Message d'accueil

Cette fonctionnalité permet de définir les informations qu'Atrium utilise lorsqu'il accueille les nouveaux membres.

## Informations clés pour une IA

- **Utilisateur principal :** administrateur du serveur.
- **Objet géré :** consignes d'accueil propres au serveur.
- **But principal :** donner à Atrium le contexte nécessaire pour accueillir les nouveaux membres de façon adaptée.
- **Exemples d'informations :** fonctionnement de la communauté, conseils aux nouveaux membres, salons importants ou règles à rappeler.
- **Règle importante :** ces consignes servent de contexte et ne remplacent pas la base de connaissances officielle.

## Résultat attendu

Après sauvegarde, Atrium utilise les nouvelles consignes lors de ses messages d'accueil sur le serveur sélectionné.
