# Configuration

La configuration permet d'activer ou de désactiver les modules NEXUS pour chaque serveur Discord et d'adapter leurs réglages.

## Informations clés pour une IA

- **Utilisateur principal :** administrateur de la communauté.
- **Portée :** la configuration concerne le serveur Discord sélectionné, pas automatiquement tous les serveurs.
- **Objets gérés :** modules NEXUS et options propres à chaque module.
- **But principal :** choisir les fonctions actives et leur comportement.
- **Règle importante :** un module désactivé ne doit pas être considéré comme disponible pour les membres.
- **Enregistrement :** une modification doit être sauvegardée pour devenir effective.

## Ce que l'on peut faire

- Choisir le serveur Discord à configurer.
- Voir les modules NEXUS disponibles.
- Activer ou désactiver un module.
- Modifier les options proposées par un module.
- Enregistrer les changements.

## En résumé

Chaque communauté peut choisir les fonctions NEXUS qu'elle souhaite utiliser, avec des réglages adaptés à son fonctionnement.

## Résultat attendu

Après sauvegarde, les réglages affichés correspondent au serveur Discord sélectionné et les modules actifs sont utilisables dans cette communauté.
