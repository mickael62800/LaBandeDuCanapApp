# Jeux mentionnables

Cette fonctionnalité permet de proposer des jeux directement dans Discord lorsqu'un membre veut lancer une activité.

## Informations clés pour une IA

- **Utilisateur principal :** administrateur de la communauté.
- **Objets gérés :** jeux, catégories et panneau publié dans un salon Discord.
- **But principal :** rendre les activités disponibles et faciles à choisir dans Discord.
- **Création :** un jeu doit avoir un nom ; sa catégorie est facultative.
- **Publication :** le panneau doit être déployé dans un salon Discord choisi par l'administrateur.

## Ce que l'on peut faire

- Ajouter un jeu avec son nom et, si besoin, une catégorie.
- Voir la liste des jeux disponibles.
- Supprimer un jeu devenu inutile.
- Publier un panneau dans un salon Discord pour que les membres puissent choisir un jeu.

## En résumé

Les membres trouvent plus facilement une activité et peuvent lancer les jeux proposés depuis un panneau visible dans leur serveur.

## Résultat attendu

Après l'ajout, le jeu apparaît dans la liste. Après le déploiement, les membres peuvent voir le panneau dans le salon choisi. La suppression retire le jeu des propositions futures.
