# Documentation Ops

Les documents fonctionnels de ce dossier constituent la référence ; aucun sous-dossier `Complet/` n'est requis.

Ops, ou « Exploitation », surveille la machine qui héberge Sentinel, NEXUS et Atrium. Cette partie est en cours de développement : les fonctions décrites correspondent aux écrans actuellement disponibles.

## Documentation détaillée

Voir la [documentation complète d'Ops](README.md), qui décrit les écrans, les données surveillées et les actions sensibles.

La documentation destinée aux développeurs et aux agents techniques se trouve dans [Ops technique](Technique/README.md).

## Règle générale pour une IA

Ops concerne la machine et les services qui y fonctionnent, pas la modération du serveur Discord et pas le contenu des serveurs de jeu. Une action Ops peut avoir des conséquences sur plusieurs plateformes.
