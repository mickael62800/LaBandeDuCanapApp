# Documentation NEXUS

## Référence commune pour les IA

- [Documentation de référence IA](REFERENCE-IA/README.md)

NEXUS est l'espace qui rassemble les jeux, les serveurs de jeu et les animations de la communauté Discord.

## Comment utiliser cette documentation

Ces documents décrivent le comportement attendu de chaque fonctionnalité NEXUS. Une IA doit utiliser le nom de la fonctionnalité, son objectif et ses règles avant de proposer une action ou une réponse. Les ressources et récompenses décrites ici sont virtuelles et propres à la communauté Discord.
