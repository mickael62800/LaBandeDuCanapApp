# Permissions et actions

## Principes

- Un membre peut utiliser uniquement les fonctions rendues publiques par la communauté.
- Un modérateur peut traiter les cas de modération selon ses droits.
- Un administrateur peut modifier la configuration de sa guilde.
- Un administrateur technique peut agir sur Ops et les services de l'hôte.
- Un superadministrateur peut accéder aux plateformes selon les règles de l'installation.

## Actions sensibles

Demander une confirmation ou orienter vers une personne autorisée avant :

- bannir, débannir, supprimer ou sanctionner ;
- restaurer ou supprimer une sauvegarde ;
- supprimer des logs ou des données IA ;
- arrêter, redémarrer ou supprimer un conteneur ;
- modifier un quota, une règle de sécurité ou une configuration globale ;
- révéler une adresse ou une information d'accès.

## Vérification minimale

Vérifier l'identité de l'auteur, la plateforme, la guilde, la cible, le droit requis et l'impact possible avant l'action.
